# 미니게임천국 — 서비스 콘셉트

## 한 줄 정의

> 미니게임천국은 JW와 그의 친구들이 게임하고, 밥 먹고, 야구 보고, 주식 얘기하는 디지털 아지트다.
> 지금은 클럽하우스지만, 궁극적으로는 친한 사람들끼리 일상을 공유하는 소셜 플레이그라운드가 될 수 있다.

---

## 서비스의 본질 — 코드가 말하는 것

이 서비스는 "불특정 다수를 위한 플랫폼"이 아니다.
**JW의 디지털 아지트**다. JW가 친구들을 초대해서 게임하고, 같이 밥 먹으러 어디 갈지 정하고, 야구 순위를 예측하고, 주식 정보를 공유하는 **친구들만의 비밀 클럽하우스**다.

코드에서 읽히는 단서들:

- `취향 알기` — 모든 질문의 정답이 JW의 답. 결과는 "JW와 매칭도 XX%". 관계를 수치화하는 도구.
- `터이네키아` — 방장(JW)이 인물을 정하고, 나머지가 맞히는 JW의 게임쇼.
- `오늘 뭐 먹지` — JW가 다니는 동네의 식당, JW가 분류한 카테고리.
- `텔레그램 봇` — 친구가 가입하면 JW에게 알림이 간다.
- `Admin 계정 단독 존재` — 이 서비스에는 왕(JW)이 있다.
- `Claude AI` 터이네키아 전용 (관리자만) — JW만 쓸 수 있는 특권.
- `비밀번호 평문 저장, RLS 비활성화` — 소규모 지인 전용이라는 무언의 선언.
- `KBO 데이터, 주간 섹터 열도 리포트` — JW와 친구들은 야구를 보고, 주식을 한다.

결론: 이 서비스의 모든 콘텐츠가 **JW라는 사람의 세계관**으로 구성되어 있다.
친구들은 JW가 만든 세계에 초대받아 노는 것이다.

## 사용자 페르소나

### JW (서비스 오너)
- 개발자, 야구 덕후, 주식 관심
- 친구들과 자주 어울리는 사람 (식당 DB가 풍부하다는 것이 증거)
- 게임을 좋아하고, 게임을 만들 줄 안다
- 친구들에게 서비스를 뽐내고 싶다
- 텔레그램으로 주간 리포트를 받는다

### 친구들 (멤버)
- JW가 초대한 사람들 (가입 알림이 JW에게 간다)
- 같이 밥 먹고, 같이 야구 보고, 같이 게임하는 사람들
- JW의 취향을 테스트해보고 싶어한다 (취향 알기)

## 현재 구조 — 5개 세계관

```
[ 미니게임천국 ] - 메인 홈
       |
  _____|_____________________________________________________
  |         |          |           |            |
[게임방]  [갓생]   [스포츠예측] [로또]     [대시보드]
  |         |          |           |            |
실시간   일상도우미   KBO예측   번호생성   금융모니터링
멀티플레이  식당추천  월드컵예측  백테스트   환율/VIX
6종게임   만다라트   텔레그램봇          공포탐욕지수
         취향알기
```

**게임방 (두뇌 미니게임)** — 6종 완성, 1종 준비중. 방 코드로 친구 초대. 실시간 멀티플레이.
타자연습 / 터이네키아 / 코브라 / 블로커스 / 할리갈리 / 아키네이터 / KOMOM(준비중)

**갓생** — 만다라트(목표 관리) / 오늘 뭐 먹지(식당 추천) / 취향 알기(JW 매칭 테스트)

**스포츠 예측** — KBO 순위 예측 + 실제 순위 비교 + 점수 계산

**로또** — 기본형 / 멤버십(고급 분석, 백테스트, 라이프 시스템)

**대시보드 + 텔레그램** — 환율/공포탐욕/VIX 모니터링 + 자동 알림봇

## 핵심 시나리오

> 저녁 7시. JW와 친구들 4명이 각자 집에 있다.
>
> 텔레그램으로 KBO 오늘 경기 결과가 자동으로 공유된다.
> "오늘 KIA 또 졌네" 라는 반응들.
>
> 누군가: "야 우리 게임 한판 하자"
> JW가 미니게임천국에서 방 만들기. 6자리 코드를 카톡에 공유.
> 친구들이 하나씩 입장. 대기실에 색깔 배지가 4개 생긴다.
>
> 게임 선택: 할리갈리. 2등 역전 옵션 ON.
> 카드를 뒤집는다. 딸기 3개, 바나나 2개...
> 누군가 벨을 친다. 틀렸다. 패널티.
>
> 10시. 다들 배가 고프다.
> JW가 "오늘 뭐 먹지?" 열어서 조건 넣기. 강남, 저녁, 삼겹살, 4명.
> 후보 2개 나옴. 친구에게 링크 공유.
>
> 내일 주식 얘기. 텔레그램에 이번 주 섹터 열도가 쌓여있다.
> 반도체 언급량 1위. 누군가 KODEX 반도체 ETF 샀다고 한다.

이것이 미니게임천국의 하루다.

## 궁극적 비전

### 비전 A — 클로즈드 소셜 게임 플랫폼
지인 기반으로 확장. 초대 코드 시스템. 그룹별 리더보드.
게임 통계 축적 (코브라 티어 시스템이 이미 씨앗).
KBO처럼 시즌제로 순위를 경쟁.

### 비전 B — 일상 큐레이션 허브
식당 추천 → 위치 기반으로 확장.
만다라트 → 공유/협업 기능 추가.
취향 알기 → 친구들끼리 서로 취향 비교 (JW 중심에서 N:N으로 확장).

### 비전 C — 정보 자동화 봇 플랫폼
텔레그램 봇이 이미 실 운영 중.
KBO → 더 많은 스포츠로 확장.
섹터 열도 → 개인 포트폴리오 연동.

### 가장 가능성 있는 방향: A + B + C
"미니게임천국"이 게임만 하는 곳에서
**친구들과 먹고 보고 투자하고 게임하는 디지털 아지트**로 진화.
