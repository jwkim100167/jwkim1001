# 🏆 MOMOK - Best

> 엄선된 맛집 카드를 라이프 포인트로 열람하는 프리미엄 맛집 추천 서비스

---

## 개요

MOMOK Best는 일반 MOMOK과 달리 **라이프(❤️) 소모 방식**으로 식당 정보를 공개합니다.
매일 첫 로그인 시 라이프가 충전되어, 하루에 열람할 수 있는 카드 수에 자연스러운 제한이 생깁니다.
카드를 열기 전에는 대략적인 위치·카테고리만 표시되어, 가볍게 탐색하다 원하는 카드만 라이프를 써서 확인하는 흐름으로 설계되어 있습니다.

---

## 라이프 시스템

| 상황 | 동작 |
|------|------|
| 매일 첫 로그인 | 라이프 **+3** 자동 충전 |
| 카드 클릭 | 라이프 **−1** 차감 후 상세 정보 공개 |
| 라이프 = 0 | 카드 클릭 차단, 안내 토스트 표시 |
| 비로그인 상태 | 카드 클릭 시 로그인 유도 토스트 표시 |
| admin / test 계정 | 라이프 차감 없이 무제한(∞) 열람 가능 |

라이프는 헤더 우측에 표시됩니다.
- **1~4개**: ❤️ 이모지 개수로 표시
- **5개 이상**: `❤️ +N개` 형식으로 표시
- **0개**: `라이프 소진` 문구 표시

## 카드 구조

카드를 **열기 전** 표시되는 정보:

```
┌─────────────────────────┐
│ ★  (리뷰 있는 카드만)   │
│  위치          세부 위치 │
│  ─────────────────────  │
│  카테고리                │
│  대표 메뉴               │
└─────────────────────────┘
```

- **★ 뱃지**: 리뷰 링크가 등록된 카드에만 노란 별 표시
- **위치 / 세부 위치**: 식당의 대략적인 지역 정보
- **카테고리**: 한식·일식·양식 등 음식 종류
- **대표 메뉴**: 해당 식당의 시그니처 메뉴

카드 **열람 후** 모달에 추가 공개되는 정보:

| 필드 | 내용 |
|------|------|
| 식당 이름 | 실제 상호명 |
| 대표 메뉴 | 시그니처 메뉴 상세 |
| 주소 | 📍 실제 주소 |
| 리뷰 보기 | 등록된 리뷰 링크 (있을 경우) |
| 네이버 지도 | 식당명 + 주소로 자동 검색 연결 |

---

## 카드 정렬 순서

1. **★ 카드 우선** — 리뷰 링크(`link`)가 있는 카드를 맨 앞에 배치
2. **카테고리 가나다순** — 같은 그룹 내에서 카테고리 기준 정렬
3. **주소 가나다순** — 카테고리가 동일하면 주소 기준 정렬

## 데이터 구조 (Supabase)

### `restaurantDataTable`

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `id` | int | PK |
| `name` | text | 식당 이름 |
| `address` | text | 주소 |
| `link` | text | 리뷰 링크 (없으면 null) |
| `bobYN` | bool | MOMOK Best 노출 여부 |
| `isOpen` | bool | 영업 중 여부 |

### `restaurantCategoryTable`

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `r_id` | int | 식당 ID (FK) |
| `category` | text | 카테고리 |
| `signature` | text | 대표 메뉴 |
| `location` | text | 지역 |
| `location2` | text | 세부 지역 |

### `userTable` (라이프 관련)

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `userLife` | int | 현재 보유 라이프 수 |
| `last_login_at` | timestamp | 마지막 로그인 시각 (날짜 변경 감지용) |

## 사용 흐름

```
접속
 ├── 비로그인 → 카드 목록 탐색 가능
 │              카드 클릭 시 "로그인 필요" 토스트 → 차단
 │
 └── 로그인
      ├── 라이프 > 0 → 카드 클릭 → 라이프 −1 → 상세 모달 표시
      │                                          ├── 리뷰 링크 이동
      │                                          └── 네이버 지도 이동
      │
      └── 라이프 = 0 → 카드 클릭 시 "라이프 없음" 토스트 → 차단
                       (다음 날 로그인 시 +3 충전)
```
